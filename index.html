受講者向けの資料をここにまとめています。スマホからも読めます。

資料

上から順に読んでください。第1週目の授業までに、必ず事前準備を終わらせておくこと。チームと席は eclass の「テーマ1（小板）：チーム分け・座席表」で決まっています。

授業前に必読
事前準備マニュアル

GitHub アカウントの作成、学生認証（GitHub Education）の申請、Visual Studio Code と Git の準備、Copilot の有効化まで。学生認証には数日〜数週間かかります。早めに着手してください。

 毎週つかう
チーム分け・座席表

JM教室のどの島に座るか。教卓に向かって、いちばん右の列が一列目。A・B・C グループを切り替えられます。第1〜4週目まで同じ席です。学籍番号つきの版は eclass にあります。

 第1週目
第1週目 進行マニュアル

当日のタイムテーブル、Copilot ハンズオン、「疑う力」演習、チームの役割決め、テーマ決定の条件、予備インタビューの進め方、宿題。授業前に一度目を通しておくこと。

 第2週目
第2週目 進行マニュアル

開始確認（git と学内の proxy の設定）、リポジトリ作成と Pull Request、公開URLで Hello World、MVP 実装、テスト協力者5人に触ってもらう宿題。授業前に一度目を通しておくこと。

参考図書

同志社SSO でログインしたうえで、電子図書館（KinoDen）から読めます。買う必要はありません。下をクリックすると、ログイン画面を経て本文に進めます。

チームと席は eclass で決まっています。学籍番号つきの図は、eclass の「テーマ1（小板）：チーム分け・座席表」にあります（このページでは公開していません）。授業前に、自分の学籍番号からチーム番号と座る島を確認してください。当日はその島に着席します。空いている席に自由に座るのではありません。
この演習の鉄則。「Copilot が書いたので分かりません」は通用しません。自分のリポジトリにあるコードは、1行残らず説明できる状態にしておいてください。動くことより、理解していることのほうが重要です。
