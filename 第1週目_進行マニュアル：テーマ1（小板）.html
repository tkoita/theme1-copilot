# ・65歳以上はシニア割引で 20% 引き
# ・12歳以下はこども料金で 50% 引き
# ・それ以外は定価
def calc_price(price, age):
    if age > 65:
        return price * 0.8
    if age < 12:
        return price * 0.5
    return price

# 参加者全員の平均料金を出す
def average_price(people):
    total = 0
    for p in people:
        total += calc_price(p["price"], p["age"])
    return total / len(people)

5-1　何をつくるのか（方向性）

つくるのは「作品」ではなく「道具」です。
誰かが毎週くり返している面倒を、1つだけ肩代わりするもの。見た目の派手さでも、技術の新しさでもありません。その人が「来週も使いたい」と言うかどうかが、唯一の評価軸です。

なぜそうするのか。Copilot を使えば、実装の速さはもう壁ではありません。この演習で問われるのは「何をつくるかを決める力」と、「つくったものを人に当てて直す力」の2つです。だから、使う相手がいないテーマは、どれだけ技術的に面白くても成立しません。

6-1　聞いてはいけないこと

✗「こういうアプリがあったら使いますか？」
誰でも「使うと思う」と答えます。親切な人ほどそう答えます。この質問からは何の情報も得られません──それどころか、「ニーズがある」という誤った確信だけが残り、いちばん危険です。

✗「〜だと便利だと思いませんか？」も同じです。未来の意見と、こちらが用意した選択肢には、価値がありません。

6-2　聞くべきこと

聞くのは過去の実際の行動だけです。この4つを順に聞いてください。

Q1起点

「最近、それで困ったのはいつですか？」

狙い「いつ」を聞くと、思い出せない＝実は困っていない、が判別できます。具体的な日付が出てこない困りごとは、たいてい存在しません。

Q2中核

「そのとき、実際にどうしましたか？」

狙いこの演習でいちばん重要な質問です。実際にとった行動には嘘がありません。「あきらめた」も立派な答えです。

Q3競合

「今は何を使って解決していますか？」

狙いあなたの本当の競合が分かります。多くの場合、それは紙とペン、LINE、あるいは「何もしていない」です。

Q4価値

「それに、時間やお金をどれくらい使っていますか？」

狙いすでに払っているものが、払ってもらえる金額の上限です。ゼロなら、有料化はほぼ不可能だと考えてください。

★の欄を、要約して書かないでください。「不便だと感じているようだった」ではなく、「毎回聞くのが申し訳なくて」のように、口から出た言葉そのままを書いてください。第4週目のピッチでは、この生の声を必ず1つ使ってもらいます。要約された言葉は、そこで使えません。

6-4　声をかけるときのマナー

相手の時間をもらっています

  • 最初に名乗る。学部・学年・氏名と、授業の課題であることを伝える
  • 所要時間を先に言い、その時間で終わらせる。「5分」と言ったら5分で切り上げる
  • 断られたらすぐ引く。食い下がらない
  • 氏名・連絡先などの個人情報は記録しない。「食堂で働く方・50代」のような属性だけで十分。部署名・年代・性別などを組み合わせると、1人に絞れてしまうことがあります。属性は大まかに書きます
  • 録音・撮影をする場合は必ず先に許可を取る
  • 終わったら礼を言う。第2週目でまた頼むかもしれない相手です

口頭での発表はしません。eclass の「テーマ1（小板）：インタビュー掲示板」へ投稿してください。スマホから投稿できます。1チームにつき投稿は1つだけで構いません。誰が投稿するかを、教室を出る前に決めておいてください。

だからこそ、自分たちの投稿も、他のグループが読む前提で書いてください。内輪の略語や、チーム内でしか通じない書き方は避けること。

① 企画シート（A4・1枚）　（チーム・前日まで）

手書きで構いません。次の4つを1枚にまとめてください。

企画シートに書くこと

  • 誰の何の課題か（人物を具体的に。PART 5 の一文をそのまま使ってよい）
  • コア機能1つ（増えていたら、この時点で減らす）
  • 誰が・いくら・なぜ払うか（PART 5 の条件3）
  • 画面のラフスケッチ（手描き可。1画面だけでよい）
インタビュー（②）の前に一度書き、聞いたあとで書き直してください。提出するのは書き直したほうです。一度も書き直していない企画シートは、話を聞いた意味がなかったということになります。第2週目の共有では「聞いて何が変わったか」を話してもらいます。
★ 書き直す前に、インタビュー掲示板を読み返してください。
① 自分のチームが投稿した「聞いて変わったこと」が、企画シートに反映されているかを確認します。投稿したのに反映されていなければ、それは聞いた意味がなかったということです。
② 他のチームの投稿も、ひととおり読んでください。同じ場所で話を聞いて、まったく違うことに気づいているチームがあるはずです。自分たちが何を見落としていたかは、他チームの投稿を読んだときにいちばんよく分かります。他のグループの投稿が既にある場合は、そちらも読んでください。

② インタビュー記録 3人分 ＋ テスト協力者5人の候補リスト　（チーム・前日まで）

今日の PART 6 で聞いた2人を、そのまま1人目・2人目として数えて構いません。つまり宿題で追加するのは1人以上です。ただし、3人のうち最低2人は「学生ではない大人」にしてください。PART 6 で学生ではない方に2人とも聞けたチームは、追加の1人は学生でも構いません。学内で働く方、アルバイト先の人、実家の家族や地元の店など、どこでも構いません。

  • 質問は PART 6 の Q1〜Q4 をそのまま使う。「使いますか？」は聞かない
  • ★「そのまま言っていた言葉」の欄が、3枚とも埋まっていること（要約しない）
  • 個人情報は記録しない。属性だけ（例：「食堂で働く方・50代」）
★ 今回から追加：テスト協力者5人の候補リスト
第2週目の宿題は「テスト協力者5人に、実際に触ってもらう」です。ここで相手が見つからなければ、その時点で詰みます。そうならないよう、今のうちに5人分を書き出しておいてください。1人につき次の3つだけで構いません。

・どんな人か（属性）　・どこに行けば会えるか　・いつなら時間をもらえそうか

★ まず、話を聞いた3人をそのまま候補に入れてください。一度話した相手は、頼めば引き受けてくれる確率がかなり高いです。ゼロから5人探すより確実です。残り2人を、チームの名簿（事前課題）で印を付けた人から選びます。

「そのへんの学生」は候補ではありません。「月曜3限のあと、食堂で会える〇〇サークルの人たち」まで具体化してください。

★ 5人のうち、最低3人は「学生ではない大人」にしてください。学生だけを5人集めたチームは、第3週目で「みんな同じことを言う」状態になり、改善の材料が得られません。1人はすでに承諾を取っておくと、第2週目以降がかなり楽になります。
